# Explainer Skills

Reusable Codex skills for explaining difficult subjects clearly.

## Included skills

- [`thing-explainer`](skills/thing-explainer/): explains complex subjects with the bundled Thing Explainer vocabulary and a deterministic word checker.

## Repository layout

Add future skills as separate directories under `skills/`:

```text
skills/
├── thing-explainer/
└── another-skill/
```

Each skill directory should contain its own `SKILL.md` and any supporting
scripts, references, or assets it needs.
